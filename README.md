# null-seal-ios

Read-only mirror of the iOS build inputs of a personal project. It is generated from a private
repository as a single snapshot commit per update; do not open issues or pull requests here, and
nothing here is licensed for redistribution.

CI in this repository builds an unsigned IPA from `core/` and `ios/` and publishes it as a release
asset with an AltStore source. No relay URL, credential or signing material lives here.

AltStore source: `https://github.com/TorresVisual/null-seal-ios/releases/latest/download/altstore.json`
